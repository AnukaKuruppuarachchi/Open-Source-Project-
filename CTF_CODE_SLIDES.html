Mode Overview

CTF is one of three subrule variants stored in an std::variant:

using all_subrules_variant = std::variant<
    bomb_defusal_rules,
    gun_game_rules,
    capture_the_flag_rules   // ← CTF
>;

The code checks which variant is active everywhere it needs to branch:

const auto is_ctf = std::holds_alternative<capture_the_flag_rules>(in.rules.subrules);

if (const auto ctf_rules = std::get_if<capture_the_flag_rules>(&in.rules.subrules)) {
    // CTF-specific logic
}

CTF Rules Struct

struct capture_the_flag_rules {
    uint32_t score_to_win = 3;       // captures needed to win
    item_flavour_id flag_flavour;    // same visual for both teams
    marker_letter_type resistance_base_letter = A;
    marker_letter_type metropolis_base_letter = B;

    marker_letter_type get_base_letter(faction_type faction) const {
        if (faction == RESISTANCE) return resistance_base_letter; // A
        return metropolis_base_letter;                            // B
    }
};

        flag.set_logic_transform(*base_pos);
        current_round.ctf_flags[flag_owner].flag_entity = flag.get_id();
    }
});

Finding the Base Position

find_ctf_base_position() scans all area_marker entities in the world:

// CTF bases reuse the bomb-site marker infrastructure
// differentiated only by their letter (A or B)

cosm.for_each_having<invariants::area_marker>([&](const auto& area) {
    if (!is_bombsite(marker.type))  return;     // must be a site marker
    if (marker_comp->letter != desired_letter)  return; // must match A or B

    result = area.find_aabb()->get_center();    // ← flag spawns here
});

Key point

CTF bases are placed in the map editor exactly like bomb sites — the letter label is all that distinguishes them. get_base_letter() maps each faction to the right letter.

Scoring a Capture

Checked every tick in mode_post_solve():

// Conditions to score:
const bool own_flag_home   = own_flag.state == AT_BASE && cosm[own_flag.flag_entity];
const bool carrier_at_base = is_inside_ctf_base(cosm, *ctf_rules, faction, pos);
const bool holding_enemy   = enemy_flag.carrier == player_id;

if (holding_enemy && own_flag_home && carrier_at_base) {
    step.queue_deletion_of(enemy_flag_entity, "CTF capture scored");
    enemy_flag = {};                      // reset enemy flag state
    s->captures += 1;                     // add to stats
    standard_victory(in, step, faction);  // check score_to_win
}

Three conditions must all be true

  • Player is carrying the enemy flag
  • Your own flag is still at its base (not stolen)
  • Player is inside their own base zone

Round Reset

At the end of the round-end delay, start_next_round() is called:

// CTF forces a FULL equipment reset — no carried weapons persist
const auto rst =
    std::holds_alternative<capture_the_flag_rules>(in.rules.subrules)
    ? round_start_type::DONT_KEEP_EQUIPMENTS
    : round_start_type::KEEP_EQUIPMENTS;

start_next_round(in, step, rst);

Then setup_round() runs again:

  • All old flag entities deleted
  • Two fresh flags spawned at A and B
  • All player inventories cleared
  • Players respawned at their faction spawns

Guards: CTF Disables Bomb Logic

CTF shares the arena with bomb-defusal infrastructure. Three explicit guards disable it:

1 — No bomb spawned on map

if (in.rules.has_bomb_mechanics() && !is_ctf) {
    give_bomb_to_random_player(in, step);
}

2 — Plant command rejected

if (!std::holds_alternative<capture_the_flag_rules>(in.rules.subrules)) {
    on_bomb_entity(in, [&](auto typed_bomb) { ... });
}

3 — Bomb win-condition skipped

if (in.rules.has_bomb_mechanics() && !is_ctf_mode) {
    /* bomb-based win conditions */
}

Summary

Round start

Delete old flags → spawn one per faction at their lettered base marker

Flag states

AT_BASE → CARRIED → DROPPED → AT_BASE

Capture

Carry enemy flag to your own base while yours is still home

Win

First to score_to_win (default 3) captures

Round end

Full inventory wipe → fresh respawn → new flags

Bomb guards

Bomb spawn, plant command, and bomb win-conditions are all blocked in CTF
